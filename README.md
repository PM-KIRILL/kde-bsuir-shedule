# Расписание БГУИР для KDE Plasma 6 (Bsuir Time Plasmoid)

[![KDE Plasma 6](https://img.shields.io/badge/KDE_Plasma-6.0+-blue.svg?logo=kde)](https://kde.org/plasma-desktop/)
[![Qt](https://img.shields.io/badge/Qt-6.6+-brightgreen.svg?logo=qt)](https://www.qt.io/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Виджет (плазмоид) расписания учебных занятий Белорусского государственного университета информатики и радиоэлектроники (БГУИР) для окружения рабочего стола **KDE Plasma 6**.

Интерфейс, визуальный стиль, цветовая палитра и алгоритмы обработки расписания переработаны и адаптированы под KDE из открытого мобильного приложения **Bsuir Time** для Android и iOS.

## Возможности

- **Аутентичный дизайн мобильного приложения**:
  - Карточка с фирменными скруглениями 20px, отступами 14px и поддержкой тем (системная тема Plasma, принудительная тёмная `#1C1C1E` или светлая `#FFFFFF`).
  - Фирменные цвета типов занятий:
    - **ЛК** (Лекция) — Зелёный (`#3FB36F`)
    - **ЛР** (Лабораторная) — Оранжевый (`#F08A24`)
    - **ПЗ** (Практика) — Фиолетовый (`#8E5CD9`)
    - **Экзамен** — Красный (`#FF3B30`)
    - **Консультация** — Голубой (`#32ADE6`)
  - Динамическая цветовая индикация даты:
    - **Синий** (`#0A84FF`) — сегодня
    - **Красный** (`#FF3B30`) — завтра
    - **Оранжевый** (`#FF9500`) — последующие дни
  - Аватары преподавателей: отображение миниатюр с перекрытием (-10px), бейджем `+N` при нескольких преподавателях, автоматическое исправление ссылок API БГУИР на фото сотрудников и всплывающие подсказки с ФИО.
  - Поддержка подгрупп: занятия чужой подгруппы выделяются полупрозрачной пунктирной рамкой.
  - Состояния пустого расписания: праздничные дни со звёздочкой (⭐), завершение всех пар на день (✓) и отсутствие занятий (📅).

- **Умное отображение и актуализация**:
  - Автоматически показывает только оставшиеся пары на сегодня с учётом текущего времени.
  - Когда все пары на сегодня закончены, виджет автоматически переключается на расписание следующего учебного дня.
  - Фоновый таймер каждую минуту пересчитывает оставшиеся пары и плавно сменяет расписание при смене дня.
  - Кнопка ручного обновления (↻) с плавной анимацией вращения при запросе к серверу.

- **Поддержка рабочего стола и панели задач**:
  - **На рабочем столе (Desktop)**: полноценная интерактивная карточка. Установлены ограничения минимального размера (не менее 280×180px), чтобы контент никогда не сминался.
  - **В панели задач (Panel)**: компактная иконка с временем ближайшей пары, открывающая всплывающую карточку по клику.

- **Офлайн-кэширование**:
  - Расписание сохраняется в локальной конфигурации виджета, поэтому оно отображается мгновенно при старте системы даже без доступа к сети.

## Требования

- **Окружение:** KDE Plasma 6.0 или новее (`plasmashell 6+`)
- **Компоненты Qt/KDE:**
  - `QtQuick`, `QtQuick.Layouts`, `QtQuick.Controls`, `QtQuick.Effects`
  - `org.kde.plasma.plasmoid`
  - `org.kde.plasma.core`
  - `org.kde.kirigami`
  - `org.kde.kcmutils`
- **Утилиты (опционально для сборки/отладки):**
  - `kpackagetool6`
  - `plasmawindowed`

## Установка

### Вариант 1. Автоматическая установка через скрипт (рекомендуется)

Клонируйте репозиторий и запустите скрипт установки:

```bash
git clone https://github.com/PM-KIRILL/kde-bsuir-shedule.git
cd kde-bsuir-shedule
./install.sh
```

Для разработчиков доступна установка в режиме символической ссылки (все изменения в коде сразу видны в Plasma):

```bash
./install.sh --symlink
```

---

### Вариант 2. Ручная установка

Скопируйте каталог виджета в директорию пользовательских плазмоидов KDE:

```bash
mkdir -p ~/.local/share/plasma/plasmoids/org.kde.plasma.bsuirschedule
cp -r metadata.json contents ~/.local/share/plasma/plasmoids/org.kde.plasma.bsuirschedule/
kpackagetool6 --type Plasma/Applet --upgrade ~/.local/share/plasma/plasmoids/org.kde.plasma.bsuirschedule 2>/dev/null || true
```

---

### Вариант 3. Сборка пакета `.plasmoid`

Вы можете упаковать виджет в стандартный архив `.plasmoid` для распространения:

```bash
# Создание пакета
zip -r org.kde.plasma.bsuirschedule.plasmoid metadata.json contents/

# Установка пакета через kpackagetool6
kpackagetool6 --type Plasma/Applet --install org.kde.plasma.bsuirschedule.plasmoid

# Или обновление, если уже был установлен:
kpackagetool6 --type Plasma/Applet --upgrade org.kde.plasma.bsuirschedule.plasmoid
```

## Использование и настройка

1. Нажмите правой кнопкой мыши по рабочему столу или панели KDE $\rightarrow$ **«Добавить виджеты…»** (или нажмите `Meta + W`).
2. В строке поиска найдите **«Расписание БГУИР»** (или `BSUIR Schedule`).
3. Перетащите виджет на рабочий стол или панель задач.
4. Нажмите правой кнопкой мыши по виджету $\rightarrow$ **«Настроить…»**:
   - **Номер группы**: укажите номер студенческой группы (например, `310101`).
   - **Подгруппа**: выберите нужную подгруппу (*Все подгруппы*, *1-я подгруппа* или *2-я подгруппа*).
   - **Тема оформления**: *Как в системе (Plasma)*, *Тёмная (Dark)* или *Светлая (Light)*.
   - **Интервал автообновления**: от 15 минут до обновления только вручную.
   - **История дня**: опция отображения прошедших пар за текущий день.

## Тестирование и отладка в отдельном окне

Для проверки работы плазмоида без добавления на рабочий стол используйте утилиту `plasmawindowed`:

```bash
plasmawindowed org.kde.plasma.bsuirschedule
```

---

## Удаление

С помощью скрипта:
```bash
./uninstall.sh
```

Либо вручную:
```bash
rm -rf ~/.local/share/plasma/plasmoids/org.kde.plasma.bsuirschedule
kpackagetool6 --type Plasma/Applet --remove org.kde.plasma.bsuirschedule 2>/dev/null || true
```
